# Translator

A funny translator. Pick who's talking and who's listening, and it rewrites what you typed in the
listener's voice, then reads it aloud.

Examples: girlfriend → regular guy, wife → husband, regular person → Jewish mom, regular person → dog
or cat, regular person → James Brown, regular person → 70s jive, 7-year-old → regular person,
regular person → teenage girl.

Status: new (2026-11-02). No design or code yet.
